# 算法与数据结构 · 第 27 课

## 二进制提升与 LCA：怎样用 O(log n) 查询一条树路径上的最大边？

**2026 年 11 月 15 日｜第 4 周 · 第 6 天｜讲授约 17 分钟（自测另计）**

> 昨天计算 MST 的唯一性、次小生成树时，对每条非树边 (u,v) 都沿树路径逐边扫描，最坏需要 O(n) 时间。今天不改变 MST 证明，而是建立一个更快的**树路径查询器**：预存向上走 1、2、4、8……条边的结果，用二进制拆分任意向上路径。

### 一、学习目标与模型（约 2 分钟）

学完应能：(1) 理解最低公共祖先 LCA；(2) 建立 `up[k][v]` 和 `mx[k][v]` 两张倍增表；(3) 手工执行“对齐深度 → 同步上跳 → 汇总两条末端边”；(4) 证明路径没有遗漏或重复；(5) 将每条非树边的 MST 换边代价查询从 O(n) 降为 O(log n)。

输入是一棵有 n≥2 个顶点的**无向加权树** T，任选根 r。边权可以为负，也可以相等。深度 depth[v] 是从根到 v 的**边数**，不是加权距离。对于不同顶点 u、v，定义

\[
M(u,v)=\max_{e\in P_T(u,v)}w(e).
\]

LCA(u,v) 是同时为 u、v 祖先且深度最大的节点。**树上唯一路径先从 u 向上到 LCA，再向下到 v**；因此可以分别向上处理两段。

### 二、示意图与动机（约 2 分钟）

~~~mermaid
flowchart TD
    A["A · depth 0"] ---|"1"| B["B · depth 1"]
    B ---|"4"| C["C · depth 2"]
    B ---|"-2"| D["D · depth 2"]
    D ---|"3"| E["E · depth 3"]
    D ---|"5"| F["F · depth 3"]
    E ---|"2"| G["G · depth 4"]
~~~

以 A 为根。查询 C 到 G 的路径是 C–B–D–E–G，路径边权为 4、−2、3、2，最大值为 4。查询 A 到 E 时，路径 A–B–D–E 的最大边权为 3。

如果用 DFS 每次重找路径，单次最坏 O(n)；若有 m 条非树边，可能需要 O(mn)。然而树结构不变，我们完全可以提前把每个顶点向上走固定长度的结果算好，重复利用。

### 三、两张倍增表：一段长度为 2^k 的摘要（约 3 分钟）

令 K=⌊log₂n⌋。定义：

- `up[k][v]`：v 向上走恰好 2^k 条边到达的祖先；若不存在记为 NIL。
- `mx[k][v]`：这 2^k 条边上的**最大权重**；若不足 2^k 条边，记为 −∞，对应祖先为 NIL。

初始 `up[0][v]=parent[v]`，有父亲时 `mx[0][v]=w(v,parent[v])`。根节点的 `up[0]` 为 NIL，`mx[0]` 为 −∞。对于 k≥1，把 2^k 条边拆成连续的两段 2^(k−1)：

\[
\begin{aligned}
a&=up[k-1][v],\\
up[k][v]&=up[k-1][a],\\
mx[k][v]&=\max(mx[k-1][v],mx[k-1][a]).
\end{aligned}
\]

**只在两段均存在时应用递推**；否则 `up[k][v]=NIL`、`mx[k][v]=−∞`。这个约定避免把不存在的祖先误当作真实顶点。注意汇总操作是 `max`，不是权重求和；换成 `sum`、`min` 等满足结合律的聚合量时也可用相同思想。

~~~text
PREPROCESS(T, root):
    DFS(root) 建立 parent、depth、parentEdgeWeight
    K = floor(log2(n))
    对每个 v:
        up[0][v] = parent[v]
        mx[0][v] = parentEdgeWeight[v] 若 parent[v] 存在，否则 -INF
    for k = 1..K:
        for v in V:
            a = up[k-1][v]
            if a != NIL and up[k-1][a] != NIL:
                up[k][v] = up[k-1][a]
                mx[k][v] = max(mx[k-1][v], mx[k-1][a])
            else:
                up[k][v] = NIL
                mx[k][v] = -INF
~~~

### 四、查询算法：先对齐，再同步上跳（约 3 分钟）

查询时维护 `ans`，表示**已经走过的边**上的最大权重。先把更深的顶点抬到与另一顶点同深度；如果已经重合，它就是 LCA。否则从最大的 k 向下检查：若两者的 2^k 祖先存在而且不同，则两者都可以向上跳 2^k 边，同时纳入这两段的最大值。结束时，它们的父亲相同，这个父亲就是 LCA；最后必须把各自到父亲的两条边也纳入。

~~~text
PATH_MAX_AND_LCA(u, v):
    assert u != v
    ans = -INF
    if depth[u] < depth[v]: swap(u,v)

    diff = depth[u] - depth[v]
    for k = K downto 0:
        if bit_k(diff) == 1:
            ans = max(ans, mx[k][u])
            u = up[k][u]

    if u == v: return (u, ans)

    for k = K downto 0:
        if up[k][u] != NIL and up[k][u] != up[k][v]:
            ans = max(ans, mx[k][u], mx[k][v])
            u = up[k][u]
            v = up[k][v]

    ans = max(ans, mx[0][u], mx[0][v])
    return (up[0][u], ans)
~~~

**数值 Trace：查询 C、G。** 两者深度分别为 2、4。先把 G 上跳 2 条边到 D，经过 G–E(2) 和 E–D(3)，所以 `ans=3`。现在 C 与 D 都在深度 2，它们的父亲同为 B，因此同步上跳阶段不再跳；最后纳入 C–B(4)、D–B(−2)，得到 `LCA(C,G)=B`，路径最大值 `M(C,G)=4`。

再查询 A、E：把 E 上跳两条边到 B（最大 3），再上跳一条边到 A（边权 1），因此 `M(A,E)=3`。**深度差的二进制分解负责“一边上升”；同步倍增负责“找到分叉处”。**

### 五、正确性证明：倍增摘要与路径分解（约 3 分钟）

**预处理不变量。** 对每个存在的 `up[k][v]`，它恰好是 v 上方 2^k 条边的祖先；`mx[k][v]` 恰好是这一整段的最大边权。k=0 由父节点定义成立；k>0 将连续路径等分为两个长度 2^(k−1) 的段，祖先可复合，最大值可取两段最大值，归纳成立。

**查询不变量。** 在任意一次上跳之后，`ans` 等于已经从原始 u、v 两端走过的边的最大权重；尚未走过的部分仍连接当前两个位置。每次跳跃的 2^k 条边由 `mx` 精确汇总，故不遗漏也不添加无关边。

对齐深度后，若 u=v，已走过的就是整条原路径。否则，从高位到低位，只在两者的 2^k 祖先不同且存在时同步上跳，因此不会越过真正的 LCA；扫描结束时二者仍不同、但父亲相同。将最后两条父边计入后，原路径被分成互不重叠的若干上跳段，`ans=M(u_original,v_original)`，公共父亲即真正 LCA。

这里的证明还说明为什么不能把两端一起跳到**相同祖先**后才停止：那样可能跨过 LCA，遗漏临近分叉处的边。

### 六、重新计算昨天的 MST 问题（约 2 分钟）

假设上图的六条树边构成已知 MST，树权重为

\[
W(T)=1+4-2+3+5+2=13.
\]

原图还有四条非树边，分别为 A–E(4)、C–G(6)、C–F(8)、E–F(7)。对每条边 e=(u,v)，用上述查询得到路径最大值 M(e)，再计算加入 e、删去原路径最大边后的增量 \(\Delta(e)=w(e)-M(e)\)。

| 非树边 e | M(e) | Δ(e) |
|---|---:|---:|
| A–E (4) | 3 | 1 |
| C–G (6) | 4 | 2 |
| C–F (8) | 5 | 3 |
| E–F (7) | 5 | 2 |

所有增量都大于零，所以这棵 MST 唯一。最小增量为 1，**严格次小生成树权重为 14**。这一步调用的是昨天证明过的 MST 换边定理；今天的倍增只负责快速、准确地计算 M(e)，没有改变最优性论证。

### 七、复杂度与边界反例（约 1 分钟）

树上 DFS 建根关系 O(n)；共有 O(log n) 层，每层处理 n 个顶点，预处理时间和空间都是 **O(n log n)**。一次查询最多遍历两轮长度 O(log n) 的位循环，因此 **O(log n) 时间、O(1) 查询额外空间**（不计预处理表）。把全部非树边查询完需 O(m log n) 时间；连同 Kruskal 构建 MST，整体可写为 \(O(m\log(m+1)+(n+m)\log n)\) 时间，存图及倍增表 O(m+n log n) 空间。

**边界 1：负边。** 不能把 `ans` 或表中“不存在的段”初始化成 0；当查询路径所有边权都为负数，0 会产生不存在的最大值，应使用 −∞。**边界 2：同一个顶点。** `P_T(u,u)` 没有边，最大边权没有通常意义；本课规定只查询 u≠v。**边界 3：动态修改。** 该表只针对静态树有效，若修改树边或其权重，应重新预处理或换用动态树结构。**边界 4：非连通图。** LCA 与路径最大值只对同一棵树内的顶点有定义；森林必须先判断是否同分量。**边界 5：不是 MST。** 任意生成树也可做倍增查询，但 \(\Delta(e)\) 可能为负，不能直接套用“已知 MST 的唯一性”结论。

### 八、小结与下一课（约 1 分钟）

\[
\boxed{\text{预处理 }2^k\text{ 级祖先和路径摘要}
\ \Longrightarrow\ \text{二进制上跳}
\ \Longrightarrow\ O(\log n)\text{ 的 LCA 与路径最大边}}
\]

今天的关键不是记住表的下标，而是理解**把长路径拆成若干不重叠的 2 的幂长度区间，并使用可结合的聚合运算**。这是数据结构预处理换取重复查询速度的经典范式。

#### Lv3｜查询边界、复杂度和 MST 唯一性｜25 分｜预计 4 分钟｜多选
