# 算法与数据结构 · 第40课

## Li Chao Tree（李超线段树）：为什么每次插入只需要递归一侧？

**2026年11月28日｜第6周第5天｜讲授约17分钟，自测另计**

上一课的单调队列凸包优化要求斜率单调、查询位置单调。如果数组包含负数，前缀和可能来回跳动，队首删除就不再安全。今天学习一种更通用的方法：不维护所有直线的显式交点，而是在一棵线段树上维护最优候选。

## 一、学习目标与问题定义（2分钟）

掌握直线交叉性质、节点中点交换、单侧递归、根到叶查询不变量，以及如何用坐标压缩将含负数的平方段和 DP 加速至 O(Kn log n)。

维护一个只增不删的直线集合，每条线为 \(f(x)=mx+b\)，支持两种操作：

- ADD(m,b,id)：插入一条在整个定义域有效的直线。
- QUERY(x)：返回已插入直线在 x 处的最小值；平局取较大的 id。

假设查询坐标已知，排序去重得到 \(X[0]<X[1]<\cdots<X[M-1]\)，M≥1。线段树划分的是这些横坐标的**下标**，不是斜率或直线编号。每个节点只存一条直线和对应区间；空节点存 NONE。

## 二、数学基础：为什么最多只递归一个孩子？（3分钟）

任意两条直线 f、g 的差为

\[
h(x)=f(x)-g(x)=(m_f-m_g)x+b_f-b_g.
\]

它是一条直线，因而两者的优劣顺序最多切换一次。相同斜率时，截距较小者在整个定义域都不差；完全重合时按 id 决定。

在节点 [l,r]，令 \(p=\lfloor(l+r)/2\rfloor\)。将当前线与新线比较，让在 X[p] 处更优者留在节点，称为 W；另一条称为 H。

假设 H 在左端优于 W。由于它在中点不优于 W，两线的优劣只能在左半段发生切换，右半段不可能再需要 H。反之，若 H 仅在右端优于 W，就只递归右半段。若两端均不优，线性函数保证整个区间都不优，可以丢弃 H。

\[
\boxed{\text{中点保留赢家，输家最多进入一个子区间。}}
\]

注意：赢家只是这两条线中在中点更优者，不保证在整个区间最优，更不保证比树中所有后代直线都优。

下面用 Mermaid 表示这个决策过程。

~~~mermaid
flowchart TD
    A["节点 [l,r]：比较已有线与新线"] --> B["交换：中点赢家 W 留在节点"]
    B --> C{"l=r？"}
    C -->|是| Z["结束"]
    C -->|否| D{"H 在左端更优？"}
    D -->|是| L["仅递归左孩子 [l,p]"]
    D -->|否| E{"H 在右端更优？"}
    E -->|是| R["仅递归右孩子 [p+1,r]"]
    E -->|否| F["H 被支配，丢弃"]
~~~

对于不等间距的离散坐标，同样使用 X[l]、X[p]、X[r] 的实际值比较。不能把下标 l、p、r 误当作横坐标。

## 三、手工 Trace：三条乱序斜率的直线（3分钟）

查询坐标为 X=[0,1,2,3,4,5,6]，依次插入 A(x)=2x+1、B(x)=−x+7、C(x)=3，id 依次为1、2、3。

初始树为空。根区间是 [0,6]，中点横坐标为3。

| 步骤 | 中点比较 | 节点变化 |
|---|---|---|
| 插入 A | 根为空 | 根存 A |
| 插入 B | B(3)=4，A(3)=7 | 根换成 B；A 在 x=0 更优，进入左孩子 |
| 插入 C | C(3)=3，B(3)=4 | 根换成 C；B 在 x=6 更优，进入右孩子 |

~~~mermaid
flowchart TD
    ROOT["[0,6] · C(x)=3"] --> LEFT["[0,3] · A(x)=2x+1"]
    ROOT --> RIGHT["[4,6] · B(x)=-x+7"]
    LEFT --> LL["[0,1] · 空"]
    LEFT --> LR["[2,3] · 空"]
    RIGHT --> RL["[4,5] · 空"]
    RIGHT --> RR["[6,6] · 空"]
~~~

查询 x=0，依次检查根 C 和左孩子 A，最小值为 min(3,1)=1。查询 x=2，比较 C(2)=3 和 A(2)=5，返回3。查询 x=6，比较 C(6)=3 和 B(6)=1，返回1。查询 x=4，C 与 B 同为3，按较大 id 返回 C。

| x | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 最小值 | 1 | 3 | 3 | 3 | 3 | 2 | 1 |
| 最优线 | A | C | C | C | C | B | B |

根只存 C，却不能只返回 C；叶子可能为空，也不表示没有答案。必须取根到目标叶路径上所有非空节点的最小值。

## 四、伪代码与正确性不变量（4分钟）

~~~text
BETTER(f,g,x):
    # f、g 均非空
    if f(x) != g(x):
        return f(x) < g(x)
    return f.id > g.id

ADD(v,l,r,h):
    if tree[v] == NONE:
        tree[v] = h
        return

    p = floor((l+r)/2)
    if BETTER(h,tree[v],X[p]):
        swap(h,tree[v])

    if l == r: return

    if BETTER(h,tree[v],X[l]):
        ADD(2*v,l,p,h)
    else if BETTER(h,tree[v],X[r]):
        ADD(2*v+1,p+1,r,h)
    # 否则 h 在整个区间都不可能更优

QUERY(v,l,r,i):
    ans = tree[v] 在 X[i] 处的 (值,id)
          # NONE 视为 (+INF,-INF)
    if l == r: return ans

    p = floor((l+r)/2)
    if i <= p:
        child = QUERY(2*v,l,p,i)
    else:
        child = QUERY(2*v+1,p+1,r,i)

    return min_by_value_then_larger_id(ans,child)
~~~

初始所有节点为空，从 ADD(1,0,M−1,h) 和 QUERY(1,0,M−1,i) 调用。这里采用固定数组实现，不需要显式创建孩子。

**核心不变量：** 对每个查询坐标 X[i]，所有已插入直线中的最优值及按规则选择的 id，等于其根到叶路径上所有已存直线中的最优结果。

证明按插入次数归纳。空树显然成立。考虑一次插入在某节点的局部操作。原线 f 和传入线 g 经交换后成为 W、H，它们在任一坐标的最优结果不变。在无需递归的半区间，W 不劣于 H，删除 H 不改变该处的最优结果；在需要递归的一侧，H 仍作为候选传入孩子，由对子区间的归纳保证它与已有后代的最优结果被保留。若两端都不优，则整个区间不优；叶子只需比较唯一坐标。其它已存候选不受影响。于是整棵树对每个查询坐标仍满足不变量。

这里同时使用两种归纳：外层对插入次数，内层对子区间长度。平局用固定 id 排序也保持至多一次优劣切换。真正安全的是被丢弃的线已有不劣的替代者，而不是假设所有节点都存全局最优线。

## 五、应用：允许负数的分段 DP（3分钟）

回顾平方段和转移，恰好分 K 个非空连续段：

\[
dp[k][i]=S[i]^2+\min_{k-1\le j<i}
\left(-2S[j]S[i]+dp[k-1][j]+S[j]^2\right).
\]

令直线斜率 m=−2S[j]、截距 b=prev[j]+S[j]²。即使 S 不单调，代数恒等式依然成立。用全部查询前缀和 S[1..n] 建立一次压缩坐标，每个 DP 层重新清空树。

取数组 [2,−3,4,1]，前缀和 S=[0,2,−1,3,4]，K=2。第一层 prev[j]=S[j]²，第二层：

| i | 新插入线 (m,b) | 查询 x=S[i] | 最优切点 j | dp[2][i] |
|---:|---|---:|---:|---:|
| 2 | (−4,8) | −1 | 1 | 13 |
| 3 | (2,2) | 3 | 1 | 5 |
| 4 | (−6,18) | 4 | 1 | 8 |

这里斜率先从 −4 增至 2，又降到 −6；单调队列的插入条件不成立。查询坐标的全序列也不保证单调。Li Chao Tree 无须这些假设，最后得到最优分段 [2] 与 [−3,4,1]，成本 2²+2²=8。

~~~text
PARTITION(a,K):
    S = PREFIX_SUM(a)
    X = SORT_UNIQUE(S[1..n])
    pos[i] = S[i] 在 X 中的下标

    prev[0] = INF
    for i = 1..n:
        prev[i] = S[i]^2

    for k = 2..K:
        clear_tree()
        cur[0..n] = INF

        for i = k..n:
            j = i-1
            if prev[j] != INF:
                ADD(line(-2*S[j],prev[j]+S[j]^2,j))
            y,id = QUERY(pos[i])
            cur[i] = S[i]^2+y

        swap(prev,cur)
    return prev[n]
~~~

扫描到 i 时，树中恰好已插入有限的合法候选 k−1≤j<i（或保留其等效替代者）。这样既允许任意斜率和查询顺序，又不会意外选择空段。

## 六、复杂度与适用边界（1分钟）

每次插入至多访问每层一个节点，每次查询也只走一条根叶路径，所以两者最坏时间均为 O(1+log M)，不是摊还界。固定数组树空间 O(M)，每层清空 O(M)。坐标排序和建立映射 O(n log n)，M≤n，因此对 n≥2：

\[
\boxed{T=O(Kn\log n),\qquad S_{\rm work}=O(n).}
\]

如果保留所有切点用于回溯，额外需要 O(Kn) 空间。

| 方法 | 必要的适用前提 | 插入/查询代价 |
|---|---|---|
| 单调队列 CHT | 斜率、查询均单调 | 摊还 O(1)/O(1) |
| 凸包+二分 | 斜率单调，查询任意 | 摊还 O(1)/最坏 O(log n) |
| 离散 Li Chao Tree | 直线全域有效，查询坐标已知 | 最坏 O(1+log M)/O(1+log M) |

边界反例：若候选为一般函数，例如 f(x)=0、g(x)=x²−1，在 [-2,2] 中点 g 更优，但两端 f 都更优，输家需要两个孩子，单侧递归证明失效。标准树不支持任意删除，也不能直接处理只在一小段区间有效的直线；后者需区间插入扩展。在线未知整数坐标可改用有界整数域动态开点，复杂度依赖坐标域大小。整数运算应防止乘法和平方溢出。

## 七、总结与下一课（1分钟）

从 CHT 到 Li Chao Tree，变化在于：从显式维护下包络的交点顺序，变成在坐标区间中隐式维护候选。最重要的两句话是“中点赢家留在节点”和“查询取整条根叶路径的最优值”。
