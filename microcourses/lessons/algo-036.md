# 算法与数据结构 · 第36课

## 分段 DP 与决策单调性：为什么最优切点不会向左退？

**2026年11月24日｜第6周第1天｜讲授约17分钟，自测另计**

上一周研究如何沿增广路改进可行解。这一周进入动态规划优化。普通 DP 往往需要枚举大量候选决策；如果能够证明这些决策的位置具有规律，就能减少搜索，而不牺牲最优性。

### 一、学习目标与动机（约2分钟）

今天掌握三个层次：建立连续分段的 DP；利用 Monge 四点不等式证明决策单调性；识别不能安全优化的输入。

例如，将一串按顺序到达的任务划分成 K 个连续批次。设任务负载为 a[i]，每个批次负载之和的平方作为代价。平方会惩罚过重的批次，因此希望在保持顺序的前提下平衡负载。要求恰好 K 个非空段，1≤K≤n。先假设元素非负，后面再讨论负数。

### 二、朴素 DP：枚举最后一刀（约3分钟）

定义前缀和 S[0]=0，S[i]=a[1]+…+a[i]。切点 j 后到位置 i 的一段包含 a[j+1] 到 a[i]，代价为

$$C(j,i)=(S[i]-S[j])^2,\qquad 0\le j<i\le n.$$

令 dp[k][i] 为前 i 个元素恰好分为 k 个非空段的最小总成本。最后一刀放在 j，便有

$$dp[k][i]=\min_{k-1\le j<i}\{dp[k-1][j]+C(j,i)\}.$$

边界：dp[0][0]=0，其余 dp[0][i] 和 i<k 的状态均为 +∞。

~~~mermaid
flowchart LR
  A["前 j 个元素<br/>已分 k−1 段"] --> B["切点 j"]
  B --> C["最后一段<br/>a[j+1] … a[i]"]
  C --> D["位置 i<br/>共 k 段"]
~~~

**正确性不变量：** 计算第 k 层之前，第 k−1 层的所有可行状态均已最优。任一合法分段的最后一刀都对应转移中的一个 j；反过来，每个有限代价的候选都可以由上一层最优解拼接出一个合法分段。按 k 归纳，取最小值就得到全局最优，而非局部贪心。

~~~text
PARTITION(a, K):
    S = PREFIX_SUM(a)
    prev[0] = 0; prev[1..n] = INF
    for k = 1..K:
        cur[0..n] = INF
        for i = k..n:
            for j = k-1..i-1:       # 升序，平局保留最小 j
                if prev[j] == INF: continue
                v = prev[j] + (S[i]-S[j])^2
                if v < cur[i]:
                    cur[i] = v
                    opt[k][i] = j
        prev = cur
    return prev[n]
~~~

### 三、数值 Trace：最佳切点真的在向右移动吗？（约3分钟）

取数组 [1,2,3,4,5]，K=2，前缀和为 [0,1,3,6,10,15]。第一层 dp[1][i]=S[i]²。第二层逐个枚举最后一刀：

| i | j=1 | j=2 | j=3 | j=4 | dp[2][i] | 最优 j |
|---|---:|---:|---:|---:|---:|---:|
| 2 | 5 | — | — | — | 5 | 1 |
| 3 | 26 | 18 | — | — | 18 | 2 |
| 4 | 82 | 58 | 52 | — | 52 | 3 |
| 5 | 197 | 153 | 117 | 125 | 117 | 3 |

例如 i=5、j=3 时，两段和分别为 6 和 9，总成本为 36+81=117。最优切点序列是 1,2,3,3。

这个现象很有用：若中间位置的最优切点为 p，左边状态只需考虑 j≤p，右边状态只需考虑 j≥p。但一个数值例子无法保证其他输入也如此，必须证明。

### 四、Monge 性质：比较四个切点（约3分钟）

取四个切点 a<b<c<d（这里 a、b、c、d 是下标）。如果区间代价满足

$$C(a,c)+C(b,d)\le C(a,d)+C(b,c),$$

就具有此处最小化问题所需的 Monge 性质（也称四边形不等式的一种形式）。

~~~mermaid
flowchart LR
  A((a)) ---|"X"| B((b))
  B ---|"Y"| C((c))
  C ---|"Z"| D((d))
~~~

设 X=S[b]−S[a]，Y=S[c]−S[b]，Z=S[d]−S[c]。左侧代价对应区间和 X+Y 与 Y+Z；右侧对应 X+Y+Z 与 Y。

直接展开得到：

$$\begin{aligned}
&C(a,d)+C(b,c)-C(a,c)-C(b,d)\\
&=(X+Y+Z)^2+Y^2-(X+Y)^2-(Y+Z)^2\\
&=2XZ\ge0.
\end{aligned}$$

最后一步使用了数组非负，因此 X、Z≥0。直观上，平方的边际代价随负载变大而增长；把两侧负载都放入同一长段，比将它们分散到两个重叠区间的总代价更大。

Monge 性质是代价函数的结构，不等于前缀和优化。前缀和只负责快速算出一个候选的代价。

### 五、核心证明：为什么 Monge 推出决策单调？（约4分钟）

固定 k≥2，令 A(j,i)=dp[k−1][j]+C(j,i)，并规定 opt[k][i] 为最小的最优切点。我们要证明：

$$i<i'\quad\Longrightarrow\quad opt[k][i]\le opt[k][i'].$$

假设反而出现逆序：p=opt[k][i]>q=opt[k][i']。于是 q<p<i<i'，两个切点在两个状态中均合法，且上一层代价有限。根据 p、q 分别最优：

$$A(p,i)\le A(q,i),\qquad A(q,i')\le A(p,i').$$

相加得到：

$$A(p,i)+A(q,i')\le A(q,i)+A(p,i').$$

另一方面，对 q<p<i<i' 使用 Monge 不等式。由于上一层的 dp 项在两侧各出现一次，它们相消，因此：

$$A(q,i)+A(p,i')\le A(q,i')+A(p,i).$$

两个不等式方向相反，只能同时取等号。特别地，A(p,i)=A(q,i)，所以 q 也是状态 i 的最优切点。但 q<p，与 p 是最小最优切点矛盾。

因此决策单调性成立。k=1 时唯一有限的切点为0，也自然成立。

**关键不是最优值单调，而是最优决策的下标单调。** 并列时统一取最小切点，是证明中排除等号逆序的必要规则之一。

### 六、复杂度、反例与优化边界（约2分钟）

朴素方法每层 O(n²)，共 K 层，时间 O(Kn²)。前缀和使每次区间代价查询 O(1)。若只求最优值，保留上一层和当前层即可，空间 O(n)；若保存全部 opt 以直接回溯分段，则空间 O(Kn)。

反例：允许负数时，取 [1,2,3,−4]，仍分成两段。i=3 时两个候选成本为26、18，最优切点为2；i=4 时三个候选成本为2、10、52，最优切点变成1。决策向左退了！

因此，区间代价能够 O(1) 计算，并不保证决策单调；即使代价是平方，也必须检查输入条件。Monge 是本课证明单调性的充分条件，而不是所有 DP 优化的必要条件。

### 七、总结与下一课（约1分钟）

$$\boxed{\text{正确的 DP 转移}\Rightarrow\text{Monge 证明}\Rightarrow\text{决策单调}\Rightarrow\text{缩小枚举范围}}$$

其中第二步需要单独证明代价函数满足相应条件，不能从任意 DP 转移直接推出 Monge。

**下一课（2026年11月25日，第37课）：分治 DP 优化。** 在已经证明决策单调的前提下，先求中点的最优切点，再递归缩小两侧的候选范围，将一层 O(n²) 转移降为 O(n log n)，总时间 O(Kn log n)。
