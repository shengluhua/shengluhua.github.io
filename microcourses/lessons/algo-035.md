# 算法与数据结构 · 第35课

## 第五周复习：如何用一张“证书”证明流和匹配已经最优？

**2026年11月23日｜第5周第7天（复习）｜讲授约17分钟，自测另计**

上一周从 Ford–Fulkerson、Edmonds–Karp、Dinic，走到二分图匹配、Hopcroft–Karp 和 Kőnig 定理。今天不新增算法，而是贯穿一条共同逻辑：**维持可行解，寻找合法的改进路径；找不到改进路径时，构造一个与当前解同值的上界证书。**

## 一、学习目标与统一路线（约2分钟）

本课要做到：①检查流的容量约束、守恒与反向残量弧；②追踪一个 Dinic 两阶段例子；③分清 Edmonds–Karp、Dinic、Hopcroft–Karp 为什么能加速；④从最大匹配直接构造最小顶点覆盖；⑤理解最优性证明中的“可行下界＝合法上界”。

~~~mermaid
flowchart TD
  A["当前可行解"] --> B{"还有改进路径吗？"}
  B -->|"有"| C["残量增广／交替翻转"]
  C --> A
  B -->|"没有"| D["构造上界证书"]
  D --> E["流：残量可达 s–t 割"]
  D --> F["匹配：交替可达顶点覆盖"]

~~~

这张图特别要记住：**算法算出一个很大的可行解，还不等于证明最优。** 最优性的最后一步通常是找到一个任何解都越不过的上界，并证明当前解恰好达到它。

## 二、残量网络回顾：纠错是合法运算，不是新建原始边（约3分钟）

对原始弧 u→v，容量 c、当前流 f，正向残量为 c−f，配对反向残量为 f。沿正向残量弧走 Δ，原流增加 Δ；沿反向残量弧走 Δ，意味着原流减少 Δ。这样既能继续使用空闲容量，也能撤销早先不合适的分配。

一条正残量 s→t 路径 P 的瓶颈为 Δ=min_{e∈P}r(e)。增广不会违反 0≤f≤c；路径内部顶点的净入/出变化相抵，源点净流出增加 Δ。**不变量**是每次操作后仍为可行流，且流值增加 Δ。

本周的三种最大流算法共享这个不变量，区别只是**怎样选路径与组织增广**。千万不要把“原始正向边没有路”误认为“残量网络没有路”：反向弧正是对先前选择进行重排的机制。

## 三、数值 Trace：同一个网络的两次 Dinic 阶段（约3分钟）

考虑下图容量网络，边标注容量，初始所有流量均为0。

~~~mermaid
flowchart LR
  S((s)) -->|"3"| A((a))
  S -->|"2"| B((b))
  A -->|"1"| T((t))
  A -->|"2"| B
  B -->|"3"| T
~~~

第一阶段的 BFS 层次为 s:0，a、b:1，t:2。同层弧 a→b 不在第一阶段的层次图内。沿 s→a→t 送1，再沿 s→b→t 送2，得到阻塞流，累计流值3。

第二阶段重新 BFS：s→a 剩余2，a→b 剩余2，b→t 剩余1，于是最短残量路径变成 s→a→b→t（长度3），再送1。最终流值是4。

| 阶段 | 最短增广路径 | 本次增量 | 累积流值 |
|---|---|---:|---:|
| 第一阶段 | s→a→t | 1 | 1 |
| 第一阶段 | s→b→t | 2 | 3 |
| 第二阶段 | s→a→b→t | 1 | 4 |

终止时从 s 可达 S={s,a,b}，t 不可达。割的跨出容量是 c(a,t)+c(b,t)=1+3=4，与当前流值4相等。因此它不仅是一个可行流，而且是最大流。

## 四、从终止条件到最优性证书（约2分钟）

任意 s–t 割 (S,V\S) 都满足

\[
|f|=\sum_{u\in S,v\notin S}f(u,v)
-\sum_{u\notin S,v\in S}f(u,v)
\le c(S,V\setminus S).
\]

原因是对 S 中各顶点的净流出求和，内部弧互相抵消，跨入 S 的流还要扣除。所以**任意可行流的值 ≤ 任意 s–t 割的容量**。

如果没有残量增广路，取 S 为从 s 沿正残量弧能到达的顶点集：所有原始 S→外部的弧都必须饱和，否则还能跨出；所有原始外部→S 的弧都必须没有正流，否则其反向残量弧还能跨出。因此净流出正好等于割容量。

\[
\boxed{|f|=c(S,V\setminus S)\quad\Longrightarrow\quad f\text{ 最大、该割最小。}}
\]

这个证明不依赖使用 DFS、BFS 还是 Dinic，也不依赖容量是否为整数。算法的**正确性证书**与**运行速度证明**是两件不同的事。

## 五、三种“按层加速”的区别（约2分钟）

| 方法 | 每次/每阶段做什么 | 提速证明关键 | 标准时间界 |
|---|---|---|---|
| Edmonds–Karp | 每轮 BFS 找一条最少边数残量路 | 残量层数不降；同向关键弧再次饱和前尾点层数至少增2 | O(nm²) |
| Dinic | 一轮 BFS 建层次图，DFS 求阻塞流 | 阻塞后，下一阶段 s→t 最短距离严格增长 | O(n²m) |
| Hopcroft–Karp | 空闲左点多源 BFS，DFS 找极大批次的顶点不相交最短增广路 | 路长逐阶段增长；对称差界定后期剩余可增广条数 | O((n+m)√n) |

这里最大流网络的 n、m 是顶点数、原始边数；HK 的 n、m 是二分图顶点数、边数，假设常规邻接表实现，单独初始化工作计入总成本。Edmonds–Karp 与 Dinic 的组合上界不依赖最大流的数值；相对地，朴素 Ford–Fulkerson 在**整数容量**时可用 O((n+m)F) 表示时间，F 为最大流值。

最容易混淆的是**阻塞流**：它只要求当前层次图不存在正残量的 s→t 路径，不要求所有边饱和。Hopcroft–Karp 的一组最短增广路只需**极大**（不能再加入不相交的同长度路径），不要求数量全局最多。

## 六、匹配—覆盖：另一个“下界等于上界”（约3分钟）

二分图 G=(L∪R,E) 的匹配 M 是不共享端点的边集，顶点覆盖 C 是能碰到每条边的顶点集。对**任何无向图**，都有 |M|≤|C|：每条匹配边需要单独一个顶点来覆盖，不能由同一个顶点覆盖两条匹配边。

二分图的特殊性质是能构造出同值的两者。把每条配对边 L→R 容量设1，加 s→L 和 R→t 的容量1弧；**整数流**与匹配一一对应，最大流值等于最大匹配大小。整数性来自零流出发、整数容量下每次增广仍保持整数，而不是所有实数可行流天然为整数。

已知最大匹配 M，从全部空闲左点沿“左→右未匹配边、右→左已匹配边”交替搜索，得到 Z_L、Z_R。构造

\[
\boxed{C=(L\setminus Z_L)\cup Z_R.}
\]

为何它覆盖全部边？左点不可达就被选入 C；左点若可达，任何相邻右点也必可达：非匹配边可直接搜索到，匹配伙伴则是进入该左点所经的前驱。为何 |C|=|M|？最大匹配意味着没有空闲右点可达；匹配边两端总是同时可达或同时不可达，因此每条匹配边恰好给 C 贡献一个端点，且 C 不含空闲顶点。由普适下界得知 C 最小。

这就是 Kőnig 定理，也是一个**具体算法产出的最优性证书**：最大匹配和最小顶点覆盖大小相等。它也体现 LP 弱对偶：匹配 LP 最大化 Σx_e，约束每点入选边总量≤1；覆盖对偶 LP 最小化 Σy_v，约束每条边 (u,v) 有 y_u+y_v≥1。任意原始/对偶可行解分别给出下界/上界；二分性保证这里存在同值整数最优解。

## 七、综合伪代码、不变量与边界（约1分钟）

~~~text
REVIEW_BIPARTITE(G):
    构造 s → L → R → t 的单位容量网络
    M = 从整数最大流中取流量为1的 L→R 弧
    Q = 所有未匹配左点
    ZL = Q; ZR = 空集
    while Q 非空:
        取出左点 u
        for 每条未匹配边 (u,v):
            if v 未访问:
                将 v 放入 ZR
                if v 匹配到左点 w:
                    将 w 放入 ZL 并入队（若尚未访问）
    C = (L \ ZL) ∪ ZR
    assert |C| == |M|
    return M, C
~~~

若匹配已知，构造覆盖只需 O(n+m) 时间、O(n) 额外标记和队列空间；先用 Hopcroft–Karp 求匹配再构造覆盖，总时间 O((n+m)√n)，总存储 O(n+m)。

**边界检查：** 无向三角形最大匹配只有1条边，而最小顶点覆盖需要2个顶点，因此不能把 Kőnig 等式用于一般图。带权收益最大匹配与最大基数匹配目标不同；允许一个顶点匹配多个对象时，需要修改容量。流网络若有真实双向边或平行边，必须给每条原始弧各自的配对反向残量弧。EK、Dinic 对精确非负实数容量仍有组合上界；浮点实现另需处理数值误差。

### Lv3｜阻塞流、匹配与覆盖的边界及复杂度｜25分｜预计4分钟｜多选

判断下列说法哪些成立。（多选；所有陈述都在通常的精确算术、合法数据结构前提下讨论。）

**A.** 任何可行流值都不超过任何 s–t 割容量，若两者相等可直接证明两者分别最优。

**B.** Dinic 一阶段求出阻塞流时，层次图中的每一条边必定被饱和。

**C.** Hopcroft–Karp 每一阶段必须找到数量全局最多的一组顶点不相交最短增广路，才能保持平方根复杂度上界。

**D.** 即使图不是二分图，若找到一组匹配 M 与一组顶点覆盖 C，且 |M|=|C|，它们也分别最优。

**E.** 标准 Hopcroft–Karp 的 O((n+m)√n) 上界针对无权二分图最大基数匹配，不能直接套用到一般带权收益最大化问题。

*中立提示：逐项分辨：最优性夹逼是否依赖二分性；阻塞意味着堵住路径还是填满边；极大批次与数量最多是否相同；算法优化的目标是否有权重。*
