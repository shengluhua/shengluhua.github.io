# 算法与数据结构 · 第 22 课

## Dijkstra：为什么“目前最近”的顶点可以永久定型？

**2026 年 11 月 10 日｜第 4 周 · 第 2 天｜讲授约 17 分钟（自测另计）**

> 昨天的 Bellman–Ford 允许负权边，靠“至多 k 条边”的逐轮松弛得到正确答案，但要反复扫描边。今天在一个关键前提——**所有边权非负**——下，使用最小优先队列，每次选出当前距离最小的顶点，并证明：它一旦被正式取出，就再也不可能被更短的路径改进。

### 一、学习目标与模型（约 1 分钟）

学完应能：①区分暂定距离、已定型距离与真实最短距离；②手工运行使用二叉最小堆的 Dijkstra；③证明“有效最小键出堆即可定型”；④分析允许重复堆条目（lazy heap）的时间、空间与边界；⑤解释负权边为什么破坏证明，明确与 Bellman–Ford、后续 Johnson 的关系。

本课处理有向图 \(G=(V,E)\)，\(n=|V|\)、\(m=|E|\)，固定源点 \(s\)，**边权 \(w(u,v)\ge0\)**，允许零权边和重边；不可达点距离为 \(+\infty\)。\(\delta(s,v)\) 表示真实最短路长度，\(dist[v]\) 是目前发现的最好路线长度。图以邻接表存储，堆项为 (距离, 顶点)。

### 二、动机：Bellman–Ford 为什么要扫描很多轮？（约 2 分钟）

Bellman–Ford 不知道某次松弛后的 \(dist[u]\) 是否已最优，所以最多需要 \(n-1\) 轮传播改进。Dijkstra 寻找能**安全停止修改**的一批顶点：已定型集合 \(S\)。

初始只有 \(dist[s]=0\)，其余为 \(\infty\)。假如未定型顶点中 \(u\) 的暂定距离最小；如果今后存在更短的 \(s\to u\) 路线，它必须跨过某个尚未定型的顶点，而**从该顶点往后走的边都非负**，不可能越走越便宜到低于眼下的最小值。这一想法将成为严格证明。

注意：“第一次发现 \(u\)”不等于“可以定型 \(u\)”；只有它以**当前有效的最小暂定距离**被取出时才可以。

### 三、有向图与手工 Trace（约 3 分钟）

考虑如下非负权有向图：

~~~mermaid
flowchart LR
    S((S)) -->|6| A((A))
    S -->|2| B((B))
    S -->|12| D((D))
    B -->|1| A
    B -->|5| C((C))
    A -->|2| C
    A -->|8| D
    C -->|1| D
~~~

我们使用允许**同一个顶点重复入堆**的简单实现：发现更短距离时 push 新的 (dist,v)，不删除堆里旧项；旧项以后弹出时被丢弃。若距离相等，按顶点字母序打破平局。

| 有效出堆 | 此轮关键松弛 | 改善后的暂定距离 (A,B,C,D) |
|---|---|---|
| S:0 | 发现 A=6、B=2、D=12 | (6,2,∞,12) |
| B:2 | A:6→3，C:∞→7 | (3,2,7,12) |
| A:3 | C:7→5，D:12→11 | (3,2,5,11) |
| C:5 | D:11→6 | (3,2,5,6) |
| D:6 | 无进一步改善 | (3,2,5,6) |

堆里还留有旧项 (6,A)、(7,C)、(11,D)、(12,D)。它们弹出时，键已不等于当前 dist，所以不会再次扩展邻边。距离为 6 的过期 A 与有效 D 谁先弹出，不影响结果。

到 D 的最短路线为 \(S\to B\to A\to C\to D\)，总代价 \(2+1+2+1=6\)。**A 先以 6 被发现，后以 3 定型；D 最初以 12 被发现，后以 6 定型。** 这就是“发现”和“定型”的区别。

### 四、Lazy-Heap Dijkstra 伪代码（约 3 分钟）

~~~text
DIJKSTRA(G, s):
    for v in V:
        dist[v] = +INF
        settled[v] = false
        parent[v] = NIL
    dist[s] = 0
    pq = min_heap()
    pq.push((0, s))

    while pq not empty:
        (d, u) = pq.pop_min()
        if d != dist[u] or settled[u]:
            continue                  # 跳过过期/重复项
        settled[u] = true             # 从这一刻永久定型

        for each edge (u, v, w) in adj[u]:
            assert w >= 0
            if not settled[v] and d + w < dist[v]:
                dist[v] = d + w
                parent[v] = u
                pq.push((dist[v], v)) # 不用 decrease-key

    return dist, parent
~~~

**流程图对应三个动作：**

~~~mermaid
flowchart TD
  P["弹出堆中最小条目 (d,u)"] --> Q{"d 是当前 dist[u] 且 u 未定型？"}
  Q -->|否| X["跳过旧条目"]
  Q -->|是| F["定型 u"]
  F --> R["扫描 u 的每条出边"]
  R --> T{"d+w 小于 dist[v] 且 v 未定型？"}
  T -->|是| U["更新 dist[v]、parent[v] 并 push"]
  T -->|否| V["不更新"]
~~~

parent 记录一条最短路线；若有多条等长最短路，严格小于比较保留先发现的其中一条。若只需要终点 t，可在**有效弹出并定型 t 时**提前停止，不能在第一次给它写入有限距离时停止。不可达点保持 \(+\infty\)。

### 五、正确性核心：定型集合的“割”不变量（约 3 分钟）

**不变量 I：** 对每个已定型 \(x\in S\)，\(dist[x]=\delta(s,x)\)；每个有限的暂定 \(dist[v]\) 都是一条真实 \(s\to v\) 路线的代价，因此始终有 \(dist[v]\ge\delta(s,v)\)。

初始化成立：s 的空路线代价为 0，其余为无穷大。沿边松弛只把一条真实路线加上一条边，所以不会凭空产生低于真实最短路的估计。

**关键归纳步骤：** 假设 S 内所有顶点均已正确定型。现从堆取出当前最小有效条目 (dist[u],u)，准备把 u 加入 S。反设存在更短的 \(s\to u\) 路线 P，长度 \(\delta(s,u)<dist[u]\)。

沿 P 从源点出发，找到**第一个尚未定型**的顶点 y，其前驱 x 必已定型。x 定型时扫描过边 x→y；因为已定型点的值正确，并且最短路径的前缀也是最短路径，故

\[
dist[y]\le dist[x]+w(x,y)
=\delta(s,x)+w(x,y)
\le \text{P 到 y 的前缀代价}.
\]

从 y 走到 u 的**路径后缀权重非负**，前缀代价不大于整条 P，因此

\[
dist[y]\le w(P)=\delta(s,u)<dist[u].
\]

这与 u 是未定型顶点中暂定距离最小者矛盾。故 \(dist[u]=\delta(s,u)\)，可安全定型。**零权边与并列出堆同样成立。**

最小堆中虽然可能有过期项，但跳过后，每个未定型且已有有限距离的点仍有对应的有效堆项；因此有效出堆仍选中最小暂定距离的点。未被访问的不可达点不会被错误定型。

### 六、复杂度：重复入堆会不会失控？（约 2 分钟）

每个顶点最多**有效定型一次**，因此其出边只扫描一次，所有边扫描次数最多 m。每次扫描至多引起一次严格改善和一次入堆，连同初始源点入堆：

\[
\boxed{\text{push 次数}\le m+1,\qquad \text{pop 次数}\le m+1.}
\]

二叉堆每次入堆或出堆用 \(O(\log(m+2))\)，数组初始化与边扫描花费 \(O(n+m)\)。lazy-heap 版本最坏时间为

\[
\boxed{O(n+m+(m+1)\log(m+2))}
\]

也可宽松写为 \(O((n+m)\log(n+m))\)。堆最多有 \(O(m+1)\) 个条目；邻接表、距离、前驱、标记数组共占 \(O(n+m)\)，故**总空间 \(O(n+m)\)**。

若堆支持 decrease-key，可让每个顶点最多有一个活动堆项，得到常见二叉堆时间 \(O((n+m)\log n)\)（\(n\ge2\)）。lazy 实现简洁，代价是旧条目占用部分堆空间。

### 七、负边反例与 Bellman–Ford 的分工（约 2 分钟）

**负边究竟破坏哪一步？** 正确性证明用到了“y 到 u 的后缀权重非负”。有很大负权边时，后面反而可能更便宜。

考虑四点图：s→a(2)、s→b(5)、b→a(−10)、a→t(1)，没有任何环。标准 Dijkstra 先以 2 定型 a、再以 3 定型 t；然而路线 s→b→a→t 的代价是 \(5-10+1=-4\)。采用永久定型、不再修改已定型顶点的标准实现就会出错。**无负环不意味着可以直接用 Dijkstra。**

Bellman–Ford 允许负边且能检测源点可达的负环，代价是多轮松弛。后续的 **Johnson 算法**将先借助 Bellman–Ford 构造势函数，把无负环图的边重赋为非负值，同时保留任意两点间路径的相对优劣，然后才安全地多次使用 Dijkstra。

其余边界：无向图中的负权边允许来回走出负权闭合游走；不可达点保持 +∞；固定宽度整数实现须防止距离加法溢出；对单个终点的提前终止应以“有效定型”为准。

### 八、小结与下一课（约 1 分钟）

\[
\boxed{\text{非负权} \Rightarrow
\text{最小暂定距离可安全定型} \Rightarrow
\text{每点只扩展一次} \Rightarrow
\text{堆优化最短路}.}
\]

Bellman–Ford 的核心是“**每轮允许更长的路线**”，Dijkstra 的核心是“**每轮证明一个点已经最优**”。

**下一课（2026-11-11，第 23 课）：Johnson 重赋权入门。** 从势函数 \(h(v)\) 出发，推导 \(w'(u,v)=w(u,v)+h(u)-h(v)\ge0\)，解释为什么最短路径次序保持不变，而不是直接背公式。
