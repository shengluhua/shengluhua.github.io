# 人工智能：理论、算法与系统 · 第 37 课

## Normalizing Flow：可逆变换、Jacobian 与精确似然

2026-11-25｜第 6 周第 2 课｜讲授约 16 分钟，测验另计

上一课 VAE 将数据似然写成潜变量积分，再用 ELBO 近似优化。今天换一种设计：要求生成映射可逆，使数据点与潜变量一一对应，从而直接计算数据密度。核心问题是：为什么从标准正态生成复杂分布时，除了移动样本，还必须修正概率密度？

## 一、从采样到密度：两个方向

设连续潜变量 \(z\in\mathbb R^d\) 服从容易采样和计算密度的基分布 \(p_Z\)，例如标准正态。定义可逆映射 \(x=f_\theta(z)\)，逆映射 \(z=g_\theta(x)=f_\theta^{-1}(x)\)。

本课假设映射在对应的开区域上是可微双射，逆映射可微，Jacobian 行列式非零。生成时用 f；密度估计时用 g。不同论文可能反过来命名 f、g，本课始终保持这一约定。

~~~mermaid
flowchart LR
  Z["潜变量 z ~ N(0,I)"] -->|"生成 fθ"| X["数据 x"]
  X -->|"密度估计 gθ = fθ⁻¹"| Z
  X --> J["逆映射 log |det Jg(x)|"]
  Z --> P["基分布 log pZ(z)"]
  P --> L["相加：log pX(x)"]
  J --> L
~~~

VAE 通常从随机的近似后验抽取 z，Flow 则在上述设定下给每个 x 唯一的 z。它并不是低维压缩器：普通双射 Flow 的输入和输出维数必须相同。

## 二、一维变量替换：概率质量守恒

假设 f 严格单调且导数不为零。在 z 附近取一段很小的区间 dz，对应 x 附近长度约为 |f'(z)| dz 的区间。变换不会丢失其中的概率质量：

\[
p_Z(z)\,dz \approx p_X(f(z))|f'(z)|\,dz.
\]

取极限得到

\[
\boxed{p_X(x)=\frac{p_Z(g(x))}{|f'(g(x))|}=p_Z(g(x))|g'(x)|.}
\]

例如 z~N(0,1)，x=2z+3，则 x~N(3,4)。对 x=3，有 z=0，因此

\[
p_X(3)=\frac{1}{2\sqrt{2\pi}}\approx0.19947.
\]

原标准正态在零处的密度约为 0.39894。横轴拉宽两倍，密度高度必须缩小一半，否则积分不再等于 1。

反过来，x=0.5z 会使分布变窄，中心密度提高为两倍。密度可以大于 1；真正不能大于 1 的是事件的概率。

导数取绝对值也有原因：x=-2z 会反转区间方向，但不会让概率密度变为负数。

## 三、多维 Jacobian：局部体积如何改变？

对于 f:R^d→R^d，Jacobian 的第 i 行第 j 列为

\[
[J_f(z)]_{ij}=\frac{\partial f_i(z)}{\partial z_j}.
\]

在 z 附近做一阶近似：

\[
f(z+\Delta z)\approx f(z)+J_f(z)\Delta z.
\]

小立方体被线性映射为平行多面体，局部体积比为 |det J_f(z)|。因此概率质量守恒给出

\[
p_X(f(z))|\det J_f(z)|=p_Z(z).
\]

由链式法则 J_g(f(z))J_f(z)=I，可得

\[
\boxed{\log p_X(x)=\log p_Z(g(x))+\log|\det J_g(x)|}
\]

或等价地

\[
\boxed{\log p_X(f(z))=\log p_Z(z)-\log|\det J_f(z)|.}
\]

记住符号：生成方向 f 扩大体积，密度应降低；使用逆方向 g 计算密度，则加逆 Jacobian 的 log-det。不能直接把 Jacobian 的迹当成普通离散 Flow 的 log-det。

## 四、二维手算：仿射 Flow

令 z~N(0,I₂)，定义

\[
x=Az+b,\quad
A=\begin{pmatrix}2&1\\0&3\end{pmatrix},\quad b=(1,-1)^\top.
\]

其行列式为 6，表示局部面积扩大六倍。若 z=(1,0)ᵀ，则 x=(3,-1)ᵀ。

二维标准正态的对数密度为

\[
\log p_Z(z)=-\log(2\pi)-\tfrac12(z_1^2+z_2^2).
\]

所以

\[
\log p_X(3,-1)=-\log(2\pi)-0.5-\log6\approx-4.12964.
\]

该变换后的均值是 b，协方差为

\[
AA^\top=\begin{pmatrix}5&3\\3&9\end{pmatrix}.
\]

它引入了相关性，但输出仍然是高斯分布。仅堆叠线性或仿射映射不能生成任意多峰分布，因为它们的复合仍是仿射映射。需要具有非线性表达能力的可逆层。

## 五、多层 Flow 的最大似然训练

设生成方向为 \(f=f_K\circ\cdots\circ f_1\)，中间状态满足 \(z_0\sim p_0,\ z_k=f_k(z_{k-1}),\ z_K=x\)。

由链式法则与 det(AB)=det(A)det(B)，

\[
\log|\det J_f(z_0)|=\sum_{k=1}^K\log|\det J_{f_k}(z_{k-1})|.
\]

所以

\[
\boxed{\log p_X(x)=\log p_0(z_0)-\sum_{k=1}^K\log|\det J_{f_k}(z_{k-1})|.}
\]

训练数据从 x 出发，依次执行逆层，得到 z₀，并计算逆向 log-det 的和。最小化平均负对数似然（NLL）：

\[
\mathcal J(\theta)=-\frac1n\sum_{i=1}^n\log p_\theta(x_i).
\]

标准正态基分布下，单样本目标可以写成

\[
\mathcal J_i=\frac12\|g_\theta(x_i)\|^2+\frac d2\log(2\pi)-\log|\det J_g(x_i)|.
\]

为什么不能删除最后一项？假设 g(x)=cx，c>0。只最小化第一项时，c 趋近零可以让所有样本的潜变量接近零，却破坏了密度的正确计算。完整 NLL 包含 -d log c，在 c 趋近零时产生发散的惩罚。这不是额外添加的经验正则，而是概率变换公式必需的体积修正。

进一步，若数据具有连续密度，且相关期望有限，则

\[
\mathbb E_{p_{\rm data}}[-\log p_\theta(X)]
=H(p_{\rm data})+D_{\rm KL}(p_{\rm data}\|p_\theta).
\]

最大似然等价于在模型族中最小化这个方向的 KL。与 VAE 不同，这里不需要为普通双射 Flow 构造潜变量积分的 ELBO；但模型容量和优化仍可能不足。

## 六、为什么不能直接使用普通 MLP？

一般神经网络并不保证可逆。例如 ReLU 会把大量负数映射到 0；降维投影也会丢失信息。即便知道某个网络可逆，求逆也可能很慢。

另一个瓶颈是 Jacobian。对 d 维的一般稠密映射，显式存储完整 Jacobian 需要 O(d²) 空间，常规稠密分解求 log-det 需要 O(d³) 算术量，另外还有构造 Jacobian 的成本。

如果 Jacobian 是三角矩阵，则

\[
\det J=\prod_{i=1}^d J_{ii},\qquad
\log|\det J|=\sum_{i=1}^d\log|J_{ii}|.
\]

当对角元素已知时，log-det 只需 O(d) 操作。这正是许多 Flow 架构选择特殊结构的原因；整个网络的前向和求逆并不因此自动成为 O(d)。

以二维非线性仿射耦合为例：

\[
x_1=z_1,\qquad x_2=e^{s(z_1)}z_2+t(z_1).
\]

逆变换为

\[
z_1=x_1,\qquad z_2=(x_2-t(x_1))e^{-s(x_1)}.
\]

Jacobian 为下三角矩阵：

\[
J_f=\begin{pmatrix}1&0\\
e^{s(z_1)}s'(z_1)z_2+t'(z_1)&e^{s(z_1)}
\end{pmatrix}.
\]

所以 \(\log|\det J_f|=s(z_1)\)。s、t 可以是普通神经网络，不必各自可逆，因为整个耦合映射的逆已经显式给出。交替交换保持不变的维度，可以让不同维度被更新。RealNVP（ICLR 2017）是这一结构的代表，下一课专门讨论它与 MAF、IAF 的计算取舍。

## 七、实现与系统直觉

~~~python
# 教学伪代码：每一层的 inverse 返回变换结果及每样本 log-det
def log_prob(x):
    z = x
    logdet = zeros(x.shape[0])
    for layer in reversed(layers):
        z, ld = layer.inverse(z)
        logdet += ld
    base_lp = -0.5 * (z*z + log(2*pi)).sum(-1)
    return base_lp + logdet

loss = -log_prob(batch).mean()
optimizer.zero_grad()
loss.backward()
optimizer.step()

# 生成：沿相反方向运行
z = randn(num_samples, dim)
for layer in layers:
    z = layer.forward(z)
samples = z
~~~

测试时检查 f⁻¹(f(z))≈z、f(f⁻¹(x))≈x，以及对应的正逆 log-det 之和约为零。使用 log 空间而不是直接连乘行列式；限制过大的缩放输出有助于减少 exp 溢出、病态逆映射及梯度不稳定。

精确似然指数学上可直接计算模型密度，不是说浮点计算没有误差，也不是说训练后模型恰好等于真实数据分布。

## 八、建模边界与实验

标准正态经过全空间微分同胚仍拥有全空间支撑，不能精确得到中间存在真正零密度间隙的分布或严格低维的奇异分布。不过它可以形成多个密度峰，并在间隙处把密度压得很低；不能把多峰和不连通支撑混为一谈。

离散像素或 Token 不是普通连续密度。对 8-bit 图像，常见处理是 dequantization，例如 x=(k+u)/256，u~Uniform[0,1)，将离散格点对应到连续区间。连续密度值不是离散概率；后者应对对应区间积分。均匀去量化训练得到的相关目标通常是离散对数似然的下界（需计入尺度常数），而不是离散概率的精确值。

建议用二维双月数据（加小幅连续噪声）比较单个仿射高斯 Flow 与多层非线性耦合 Flow。固定训练/测试划分、基分布、优化预算与随机种子组；报告 held-out NLL、采样散点与覆盖率、逆变换误差、正逆 log-det 误差、训练时间、采样和密度评估耗时。比较 VAE 时需注明 ELBO 是下界，不能直接将其当作精确 NLL；比较离散数据必须统一去量化与单位。

易错反例：

| 误解 | 正确边界 |
|---|---|
| f 可逆就不需要 Jacobian | 非保体积映射必须修正密度 |
| Jacobian 行列式可以为负，所以密度也为负 | 使用绝对值 |
| 一般 MLP 都可以做普通双射 Flow | 要求全局可逆及可行的逆与 log-det |
| 多个仿射层能表达任意复杂分布 | 仿射复合仍是仿射 |
| O(d) log-det 就是 O(d) 整个网络 | 还要计入神经网络及逆向计算 |
| 精确似然意味着生成质量完美 | 只是模型密度可计算，仍需泛化与采样评估 |

经典理论是变量替换、概率质量守恒、Jacobian 和最大似然；RealNVP 等可逆神经网络属于具体研究架构，性能与表达能力需要结合实验验证。

参考：[Papamakarios 等，Normalizing Flows for Probabilistic Modeling and Inference（JMLR 2021）](https://www.jmlr.org/papers/v22/19-1028.html)；[Dinh 等，Density Estimation Using Real NVP（ICLR 2017）](https://arxiv.org/abs/1605.08803)。
