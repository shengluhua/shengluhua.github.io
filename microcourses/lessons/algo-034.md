# 算法与数据结构 · 第34课

## Kőnig定理：为什么二分图的最大匹配数恰好等于最小顶点覆盖数？

**2026年11月22日｜第5周·第6天｜讲授约17分钟（自测另计）**

> 昨天 Hopcroft–Karp 回答“最多能配对多少组”；今天问一个看似相反的问题：**最少选出多少个人或任务，使每条可行配对关系都至少碰到一个被选顶点？** 惊人之处是：在二分图中，这两个最优数字永远相等。我们不只记住等式，还要从最大匹配构造出最小覆盖，并说明为什么一般图不成立。

## 一、学习目标与定义（约2分钟）

本节目标：①区分匹配和顶点覆盖；②掌握从最大匹配出发的交替可达搜索；③证明 Kőnig 定理的两边不等式；④把匹配与顶点覆盖写成一对线性规划原始/对偶问题；⑤掌握非二分图反例和算法复杂度。

设无权二分图 G=(L∪R,E)，边只连接左右两侧。**匹配** M⊆E 中的任意两条边没有公共端点；最大匹配令 |M| 尽量大。**顶点覆盖** C⊆L∪R 满足：对于每条边 (u,v)∈E，至少有一个端点在 C 中；最小顶点覆盖令 |C| 尽量小。

注意顶点覆盖不是“选到所有顶点”，也不是边覆盖（edge cover）。选中的顶点只需碰到每一条边即可。

## 二、先看一个普适下界（约2分钟）

对**任何无向图**，都成立：

\[
\boxed{|M|\le |C|\quad\text{（任意匹配 M、任意顶点覆盖 C）}.}
\]

原因：匹配的 |M| 条边两两没有公共端点；要覆盖每条匹配边，至少得为每条边选一个端点，而同一个顶点不可能覆盖两条不同的匹配边。因此最大匹配数是最小覆盖数的下界。

但**下界不保证能达到**。三角形有三条边：最大匹配只能选一条边，大小为1；最小顶点覆盖要选两个顶点，大小为2。Kőnig定理的特殊性正在于：**如果图是二分图，这个普适下界一定能达到。**

## 三、一个具体二分图（约2分钟）

令 L={A,B,C,D}、R={1,2,3}，边集：

\[
E=\{A\!-\!1,\ B\!-\!1,\ B\!-\!2,\ C\!-\!2,\ D\!-\!2,\ D\!-\!3\}.
\]

取一组匹配 M={A–1,B–2,D–3}，大小3；右侧只有3个顶点，因此 M 已经是最大匹配。

问题：能否只选3个顶点，就覆盖图中全部6条边？下一步提供一个**可计算的构造**，而非凭观察猜测。

## 四、交替可达搜索：怎样构造覆盖（约3分钟）

以 M 为当前最大匹配，从**所有未匹配左点**同时开始搜索。只允许两种走法：

1. 从左点向右点，只沿**未匹配边**走；
2. 从右点返回左点，只沿**已匹配边**走。

记所有可达左点为 Z_L，可达右点为 Z_R。构造：

\[
\boxed{C=(L\setminus Z_L)\cup Z_R.}
\]

文字解释：**选所有没被交替搜索到的左点，加上所有被搜索到的右点。**

本例唯一未匹配左点为 C。数值 Trace 如下：

| 步骤 | 交替搜索动作 | 新到达的顶点 |
|---|---|---|
| 0 | 从未匹配左点开始 | C |
| 1 | C 经未匹配边 C–2 | 右点 2 |
| 2 | 2 沿已匹配边 2–B 回退 | 左点 B |
| 3 | B 经未匹配边 B–1 | 右点 1 |
| 4 | 1 沿已匹配边 1–A 回退 | 左点 A |
| 5 | A 没有其他未匹配出边，搜索结束 | 无 |

~~~mermaid
flowchart LR
  C["C：空闲左点"] -->|"未匹配 C–2"| R2["2"]
  R2 -->|"已匹配 2–B"| B["B"]
  B -->|"未匹配 B–1"| R1["1"]
  R1 -->|"已匹配 1–A"| A["A"]
~~~

所以 Z_L={C,B,A}，Z_R={2,1}，左侧没有到达的只有 D。因此 C（覆盖集合）={D,1,2}，大小为3。检查原始6条边：A–1、B–1 被顶点1覆盖；B–2、C–2、D–2 被顶点2覆盖；D–3 被顶点D覆盖。配合刚才的下界 |M|≤|C|，这个大小3的覆盖必然最小。

这里“C”既是左侧顶点名，也是覆盖集合的常用记号；上下文中用“顶点 C”和“覆盖集合 C”区分即可。

## 五、证明：为什么这个构造永远正确？（约3分钟）

**第一步：证明 C 真能覆盖所有边。** 任取原边 (u,v)，其中 u∈L、v∈R。若 u 不可达，即 u∉Z_L，则 u 已被选入 C，此边被覆盖。若 u∈Z_L：当 (u,v) 未匹配，搜索规则会由 u 到达 v，因此 v∈Z_R；当 (u,v) 已匹配，由于匹配左点 u 不可能是空闲搜索起点，它能被访问必是从其匹配伙伴 v 沿已匹配边回退，因此 v∈Z_R。两种情形都覆盖该边。

**第二步：证明 |C|=|M|。** 因为 M 最大，不存在增广路，所以**没有未匹配右点可达**：否则从空闲左点沿交替路径走到空闲右点，就形成增广路。每个可达右点都已匹配；每个不在 Z_L 中的左点也必已匹配，因为所有空闲左点都是搜索起点。

对于任意匹配边 (u,v)，有：

\[
\boxed{u\in Z_L\iff v\in Z_R.}
\]

右点 v 可达时，沿其匹配边可到 u；匹配左点 u 可达时，它必是经其匹配右点 v 到达。于是每条匹配边恰好给 C 贡献一个端点：两端都可达时选右端；两端都不可达时选左端。同时 C 不含任何未匹配顶点，所以 |C|=|M|。

**第三步：最优性夹逼。** 对任意匹配 M'、任意覆盖 C'，都有 |M'|≤|C'|；我们构造出某个覆盖 C，满足 |C|=|M|。因此 M 最大且 C 最小，且：

\[
\boxed{\nu(G)=\tau(G)\qquad\text{（二分图的 Kőnig 定理）}.}
\]

其中 \(\nu(G)\) 是最大匹配边数，\(\tau(G)\) 是最小顶点覆盖大小。**已知一组最大匹配后，仅一次交替搜索就能拿到对应的最小覆盖。**

## 六、为什么这也是线性规划对偶？（约2分钟）

为每条边设变量 x_e，表示是否选择这条匹配边。最大匹配的整数规划为：

\[
\max\sum_{e\in E}x_e,\qquad
\sum_{e\ni v}x_e\le1\ (\forall v),\quad x_e\in\{0,1\}.
\]

先把 x_e 改成实数 x_e≥0，得到一个 LP 松弛（单点约束自动给出 x_e≤1）。它的线性规划对偶为：

\[
\min\sum_{v\in V}y_v,\qquad
y_u+y_v\ge1\ (\forall (u,v)\in E),\quad y_v\ge0.
\]

若 y_v 只取0或1，它正好表示是否把顶点 v 放进覆盖。任何原始可行 x 和对偶可行 y，都满足**弱对偶**：

\[
\sum_e x_e
\le\sum_e x_e(y_u+y_v)
=\sum_v y_v\sum_{e\ni v}x_e
\le\sum_v y_v.
\]

在二分图中，我们构造出了同值的**整数**匹配与覆盖，说明这对 LP 都存在整数最优解；换言之，这里没有“松弛后变好”的整数间隙。

为什么二分性重要？在三角形中，给每条边 x_e=1/2，满足各顶点约束且 LP 目标为 3/2；给每个顶点 y_v=1/2，也满足所有覆盖约束且目标为3/2。可是整数最大匹配是1，整数最小覆盖是2。LP 的 3/2 不等于任何一个整数最优值，Kőnig等式也不成立。

## 七、算法伪代码、复杂度与前提边界（约2分钟）

~~~text
MIN_VERTEX_COVER_FROM_MAX_MATCHING(G, M):
    ZL = set of unmatched left vertices
    ZR = empty set
    queue = all vertices in ZL
    while queue is not empty:
        u = pop(queue)                    # u is a left vertex
        for each unmatched edge (u,v):
            if v not in ZR:
                add v to ZR
                if v is matched to w:      # w is a left vertex
                    if w not in ZL:
                        add w to ZL
                        push w into queue
                # unmatched v would reveal an augmenting path
    return (L \ ZL) union ZR
~~~

**循环不变量**：Z_L、Z_R 正好记录目前已沿合法交替方向发现的顶点；每个入队左点都有一条从某个空闲左点出发的交替路径；每个右点仅首次访问，队列结束时得到完整交替可达集合。**输入 M 必须是最大匹配**，才能用“右侧不存在空闲可达点”和 |C|=|M| 的证明。

如果已知 M，邻接表搜索及集合输出需 **O(n+m) 时间、O(n+m) 总存储（含图），或 O(n) 额外标记/队列空间**。如果先用 Hopcroft–Karp 求 M，再求 C，总时间 **O((n+m)√n)**、总空间 O(n+m)；这里 n=|L|+|R|、m=|E|。

反例边界：对非二分图，一般不适用此构造；如果给定的 M 不是最大匹配，搜索可能抵达空闲右点，不能宣称得到最小覆盖；如果问题变成**带权顶点覆盖**，要使用带权最小割等方法，而不是直接按顶点数量套用等式。
