一、已核实的公开复习范围

下列八个模块来自公开复习网站。它们只是目前可读的范围，不代表尚未读取的 PDF 已全部涵盖。网站部分条目要求参考 PPT，因此不能只依靠网页形成最终课表。

模块已看到的范围拟采用的讲解方式
互斥与并行Amdahl、Safety / Liveness / Fairness、LockOne、LockTwo、Peterson线程交错逐步播放；逐条验证安全性与进展性，写清内存模型前提。
布尔代数Cofactor、Shannon 展开、布尔差分、量词、网络修复真值表与 MUX 同步变化；代入、化简、量词消除不跳步。
逻辑综合SOP / POS、两级与多级优化、technology mapping、tree covering逻辑图逐步改写，库匹配和动态规划成本逐节点计算。
布局模拟退火、划分、线长模型、二次与非线性解析布局拖动单元显示目标变化；区分真实约束、代理目标与优化假设。
布线Steiner 树、Hannan 网格、FLUTE、Lee、Akers 编码逐层波前传播、逐边回溯；区分拓扑类别与具体坐标权重。
静态时序分析时序图、cell/net arc、AT / RAT / slack、setup / hold沿图传播时间，逐步写出 max/min 的来源与约束符号。
体系结构CPU 时间、CPI、流水线与三类 hazard逐周期执行表，明确理想模型与真实停顿的区别。
存储系统层次存储、locality、Cache hit/miss、memory stall地址拆分与访存 trace，同一例子逐次计算命中及周期成本。

二、考试线：重点必须有依据

课程区分三种标签：复习范围明确出现、往年真题实际考过、为理解而补充。只有读到试卷原文后，才添加题号、分值及“真题已考”标签；不编造高频考点或今年命题趋势。

每道真题按“题面与条件 → 对应知识 → 最小解题步骤 → 易错符号与边界 → 得分步骤 → 变式练习”讲解。计算题展示中间数值，证明题标出使用的假设，算法题保留每一步状态。

2025 年试卷状态：未读到正文。当前不能给出真实题目分布、分值权重或逐题解答。正式试卷解析与日常自测分开，自测第一次展示不泄露答案。

三、实验线：从代码入口讲到验证与报告

已核实的参考仓库 pku-gsun/dacs-lab 列出下面三个实验，分支属于 dacs2024。尚不能把它们认定为指定材料仓库中的 2025 年实验版本。

参考实验 1｜前缀加法器设计优化

教学拆解：进位 generate/propagate → 前缀算子与拓扑 → 设计编码 → 生成 RTL → 正确性检查 → PPA 测量 → 面积/延迟权衡。具体函数、配置和评分方式以核验后的实验源码为准。

参考实验 2｜EDA 流程参数调优

教学拆解：设计与工艺库输入 → 参数空间 → 工具流程调用 → 日志/报告解析 → 目标函数 → 搜索策略 → 重复实验与消融。须检查失败状态、版本依赖与资源预算。

参考实验 3｜AI 加速器设计优化

教学拆解：工作负载 → 架构参数与映射 → 容量/带宽约束 → 代价模型 → 设计空间搜索 → 结果验证。实际接口、工具和交付要求待仓库源码核对。

每个实验固定交付

源码阅读图、环境与版本清单、逐条命令及用途、最小可验证样例、关键代码讲解、测试方法、日志定位、基线与消融表、报告结构。严格区分“原实验规定”“新增教学练习”“已实测”“未运行”。没有 Genus/Innovus 许可或 GPU 设备时，不伪造实验结果。

参考仓库 README 列有 Python ≥3.12、Cadence Genus / Innovus 与 ASAP7 库。最终要求必须按实际课程版本重新确认。

四、每节讲解：让推理过程可见

01 问题与输入要解决什么？符号、单位、约束是什么？
02 直观模型先画结构、状态或几何关系，再引入公式。
03 逐步推导每次等号和不等号写明依据，代码索引逐项解释。
04 检验与变式算例、反例、边界条件，再用递进题检测。

理论单元拟按约 25–40 分钟的阅读量拆分；实验讲解独立成节，允许更长。内容量由材料决定，不强行压缩成固定 12 周，也不为保持短篇而省略证明。学习时长仅为阅读规划，不代表工具运行耗时。

每节保留 Lv1–Lv4 四道递进自测，15/20/25/40 分。前三题客观判分，证明、程序设计和实验报告需自评或人工/ChatGPT 批改。可视化提供暂停、单步、参数修改与文字等价说明，平板阅读不依赖悬停。
